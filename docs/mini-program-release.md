# 微信小程序正式发布清单

## 1. 小程序后台

- 使用真实 AppID 替换 `miniprogram/project.config.json` 中的 `appid`。
- 完成小程序名称、头像、简介、服务类目配置。
- 配置用户隐私保护指引。项目使用 `wx.getLocation`，需要说明定位用途：在地图上显示当前位置并进行周边文保单位查询。
- 开发管理 → 开发设置 → 服务器域名 → request 合法域名：添加后端 HTTPS 域名。

## 2. 后端域名

- 必须使用 HTTPS。
- 不要使用 IP 地址、localhost、非 443 端口或自签名证书。
- 生产环境将 `miniprogram/config.js` 的 `API_BASE` 改为正式域名。

## 3. 上传审核

1. 微信开发者工具导入 `miniprogram`。
2. 本地调试通过后，取消“开发环境不校验合法域名、TLS 版本以及 HTTPS 证书”。
3. 点击“上传”，填写版本号与说明。
4. 到微信公众平台提交审核。
5. 审核通过后点击发布。

## 4. 审核风险

- 页面不要出现明显的“测试”“临时”“localhost”等字样。
- 后端必须稳定可访问。
- 定位权限必须有清晰用途说明。
- 若使用个人主体小程序，服务类目能力可能受限制；课程展示通常足够，但正式长期运营建议使用学校/组织主体。
