# 用自己的电脑当服务器，在手机上测试小程序

目标：不发布正式版，只在自己的手机上扫码预览/真机调试。

## 第 1 步：电脑和手机连接同一个 WiFi

必须是同一个局域网。不要让手机使用流量。

## 第 2 步：启动后端服务

打开 PowerShell，执行：

```powershell
cd E:\jiyuweizhidefuwudazuoye\heritage-lbs
.\scripts\start-phone-test.ps1
```

脚本会自动完成：

- 找到你电脑的局域网 IP
- 修改 `miniprogram/config.js`
- 把 API 地址改成 `http://你的电脑IP:3000/api/v1`
- 启动 Node 后端服务

这个 PowerShell 窗口不要关闭。关闭后手机就访问不到服务。

如果 Windows 防火墙弹窗，选择“允许访问”。

## 第 3 步：用手机浏览器测试 API

脚本会显示一个地址，例如：

```text
http://192.168.1.23:3000/api/v1/health
```

用手机浏览器打开它。如果能看到 JSON，说明手机能访问电脑服务。

如果打不开，通常是以下原因：

- 手机和电脑不在同一个 WiFi
- 电脑防火墙拦截了 3000 端口
- 电脑连了 VPN，导致局域网访问异常
- 脚本识别到了错误的网卡 IP

## 第 4 步：微信开发者工具设置

打开微信开发者工具，导入：

```text
E:\jiyuweizhidefuwudazuoye\heritage-lbs\miniprogram
```

进入：

```text
详情 → 本地设置
```

勾选：

```text
不校验合法域名、web-view、TLS 版本以及 HTTPS 证书
```

这是本地手机测试必须做的。正式发布时不能依赖这个选项。

## 第 5 步：手机运行

推荐先用“真机调试”。

如果真机调试可以正常显示地图和 POI，再使用“预览”生成二维码。

## 第 6 步：测试功能

建议按这个顺序测试：

1. 地图页能加载 POI 列表
2. 搜索“三塔”
3. 点击“当前视野”
4. 手机授权定位后点击“周边 10km”
5. 进入详情页，点击“地图导航”
6. 账户页登录 `demo / Demo@123456`
7. 维护页登录 `admin / Admin@123456`

## 重要限制

这种方式只适合自己手机测试。

原因：

- API 地址是你电脑的局域网 IP，别人离开你的 WiFi 就访问不到
- HTTP 本地地址不能用于正式发布
- 正式发布必须使用公网 HTTPS 域名，并在微信公众平台配置 request 合法域名
